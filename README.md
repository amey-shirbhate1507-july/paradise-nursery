# Paradise Nursery Shopping Application

## Project Description
Paradise Nursery is a dynamic, interactive web-based shopping cart application for an online plant shop. Built with React and Redux Toolkit, it allows users to browse various categories of houseplants, view detailed plant information (including thumbnails, names, descriptions, and prices), and seamlessly manage their shopping cart. 

## Features
* Interactive Landing Page with a "Get Started" button.
* Product Listing categorized with at least 6 unique houseplants per category.
* Redux state management for adding, removing, and updating cart quantities.
* Real-time calculation of total costs and total cart items.
